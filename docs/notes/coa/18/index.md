## I/O 的寻址方式

- **独立编址** I/O 端口与存储器完全分开
- **统一编址** 由地址线高位确定，一般 I/O 是 1，存储器是 0

## 主机和外设的信息传送

### 控制方式

- 程序查询方式
- 程序中断方式
- 直接内存访问方式（DMA）
- 通道方式
- 外围处理机方式

<br>

- **程序查询方式:** 主机用测试指令不断查询外设的动作状态
- **程序中断方式:** 外设完成准备工作向 CPU 发出中断请求，请求 CPU 为自己服务，CPU 暂时停止正在执行的程序，转去执行终端服务程序，为中断请求者服务，在中断服务程序中完成一次 CPU 与外设之间的数据传送。传送完成后 CPU 返回原来的程序从断点处继续执行

### 中断屏蔽

用程序方式选择性地封锁部分中断。

- 中断响应优先级: 硬件决定
- 中断处理优先级: 中断屏蔽字
