# 组合逻辑电路

> [!NOTE] 复习重点
> 1. 组合逻辑电路
>    - 基本单元是门电路
>    - 输出仅取决于输入信号，与原来的状态无关
> 2. 门电路
>    - 是数字集成电路中最基本的逻辑单元
> 3. 集成电路
>    - MOS 型（基本单元: MOS 场效应管(FET)）
>      - CMOS
> 4. CMOS 门电路及 TTL 门电路的应用
> 5. 组合逻辑电路的分析方法（电路→功能）
>    - 化简函数表达式
>    - 真值表
>    - 电路的逻辑功能
> 6. 组合逻辑电路的设计方法（功能→电路）
>    - 逻辑抽象 → 写出函数式 → 选定器件类型 → 对逻辑式化简 → 画出逻辑电路图
> 7. 常用的逻辑电路
>    - 编码器、译码器、数据选择器、加法器
>
> - **重点一**: 组合逻辑电路的分析方法（分析给定电路的逻辑功能）
> - **重点二**: 组合逻辑电路的设计方法（用门店路或者译码器设计给定功能的逻辑电路）


## 概述

- **数字电路:** 组合逻辑电路，时序逻辑电路
- **组合逻辑电路:** 输出仅取决于当时的输入信号，与电路原来的状态无关
- **特点**:
  - 结构 只由逻辑门电路组成，没有记忆单元
  - 功能 只由从输入到输出的通路，没有输出反馈到输入的回路

## 逻辑门电路

### 概述

- **概念**
  - 实现基本逻辑运算、复合逻辑元算的单元电路。
  - 门电路是数字集成电路中最基本的逻辑单元
- **高低电平表示 1/0**
  - 正逻辑，负逻辑
- 获取高低电平的基本开关电路
- 集成电路
