# 计算机中数据信息的表示

## 进位计数制

十进制、二进制、十六进制数及相互转换（除基取余，乘基取整）

## 机器数的编码表示

原码、反码、补码、移码的转换方法

$$
\begin{gather*}
    \begin{cases}
        [X]_\text{原} = [X]_\text{反} = [X]_\text{补} & x \ge 0\\
        [X]_\text{原} \xrightarrow{符号位不变，其余取反} [X]_\text{反} \xrightarrow{\text{低位} + 1} [X]_\text{补} & x < 0
    \end{cases}\\
    [X]_\text{移} = x + 2^n
\end{gather*}
$$

## 数的定点表示与浮点表示

定点数和浮点数的表示方法及其数据的范围

## 规格化浮点数的概念及计算

尾数不为 0 时满足 $0.5 \le \lvert M \rvert < 1$

## IEEE754 浮点数

float

- S = 符号位
- E = 阶码 8 位，用移码表示（只偏移 $2^7 - 1$）
- M = 尾码 23 位，纯小数表示，隐藏最高位

特殊的存储规则

- 正 0: 所有数据位都是 0
- 负 0: 最高位为 1 其他数据位是 0
- 正 / 负无穷: 阶码全为 1，有效数字全为 0
- NAN: 阶码全为 1，有效数字不全为 0
