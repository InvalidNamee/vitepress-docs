# AGENTS.md

This file provides guidance to Codex (Codex.ai/code) when working with code in this repository.

## Project overview

A personal VitePress documentation site hosting ACM/competitive programming solution write-ups and university course notes (physics, discrete math, data structures, psychology). Content is in Chinese.

## Commands

```bash
npm run docs:dev      # Start dev server (http://localhost:5173)
npm run docs:build    # Production build
npm run docs:preview  # Preview production build locally
```

There are no tests, linting, or type-checking configured.

## Architecture

### Content structure

```
docs/
  index.md                 # Landing page (home layout)
  acm/                     # ACM solution write-ups
    {platform}/            # e.g. AcWing/, CSES/, GPLT/, ICPC/, lanqiao/
  notes/                   # University course notes
    {subject}/             # e.g. uni-phys/, data-structure/, decrete-math/
  public/                  # Static assets (favicon, ICP filing images)
  .vitepress/
    config.mts             # Full site configuration
    theme/
      index.ts             # Theme entry — imports default theme + plugins
      styles.css           # Hero gradient, Persian font fallback, search tweaks
```

### Key configuration details

- **Sidebar**: Auto-generated by `vitepress-sidebar`. The `config.mts` defines three scan zones — `acm/`, `notes/`, and root — each with `useTitleFromFileHeading`, `useFolderTitleFromIndexFile`, and `collapsed: true`. Adding a new Markdown file inside `acm/` or `notes/` is automatically picked up.
- **Math**: LaTeX math rendering is enabled via `markdown.math: true` (built-in VitePress math support, backed by `markdown-it-mathjax3`).
- **Group icons**: `vitepress-plugin-group-icons` is registered both as a markdown plugin (`groupIconMdPlugin`) and a Vite plugin (`groupIconVitePlugin`), with `virtual:group-icons.css` imported in the theme.
- **URLs**: `cleanUrls: true` — `/acm/` resolves to `/acm/index.md`.
- **Search**: Local search provider.
- **ICP filing**: The footer includes Chinese ICP registration numbers and links to government verification pages.

### Theme customizations

The custom theme (`docs/.vitepress/theme/`) extends the VitePress default theme, adding:
- A gradient for the hero name on the landing page (`--vp-home-hero-name-background`)
- A Persian (Farsi) font family fallback (`Vazirmatn`) for multilingual support
- Drop shadow on the hero image
